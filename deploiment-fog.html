Déploiement FOG

Synchroniser l'OS de tous les PC d'une salle de cours automatiquement via le réseau

Le Problème à Résoudre

Dans une salle de classe avec 20 PC, installer un système d'exploitation sur chaque poste à la main est un cauchemar. Il faut une clé USB, passer sur chaque PC, attendre 30 minutes par installation... Multiplié par 20 postes, ça devient vite ingérable.

Et si un PC plante ou qu'on veut changer de système (Windows → Ubuntu), il faut tout recommencer. C'est exactement le problème qu'on avait au lycée.

La Solution : FOG Project

FOG Project est un logiciel libre qui permet de déployer des systèmes d'exploitation sur plusieurs ordinateurs simultanément via le réseau. Pas besoin de clé USB, pas besoin de passer sur chaque poste : tout se fait depuis un serveur central.

Ce que FOG permet

  • Déployer Windows ou Ubuntu sur 20 PC en même temps
  • Choisir depuis le poste du prof quel système installer
  • Tout faire automatiquement via le réseau (PXE boot)
  • Gérer les installations depuis une interface web simple
  • Stocker plusieurs images systèmes et les déployer en quelques clics

Interface web de FOG pour gérer les déploiements

Comment Ça Fonctionne

Le principe est simple mais puissant. Voici le workflow complet :

1
Boot PXE

Les PC démarrent sur le réseau au lieu du disque dur

2
Choix du Prof

Depuis son PC, le prof choisit l'image à déployer (Windows ou Ubuntu)

3
Déploiement

FOG envoie l'image sur tous les PC simultanément via multicast

4
Redémarrage

Les PC redémarrent automatiquement sur le nouveau système

Architecture du Projet

Pour que tout fonctionne, on a mis en place une infrastructure complète :

Matériel Nécessaire

  • Serveur FOG : PC dédié sous Debian 12 (pas besoin qu'il soit puissant)
  • 20 PC clients : Les postes de la salle de classe
  • Switch réseau : Pour relier tous les postes en Ethernet
  • Câbles RJ45 : Connexion filaire obligatoire (le Wi-Fi ne marche pas pour PXE)
  • PC prof : Pour gérer les déploiements via l'interface web

Salle de classe avec tous les PC reliés au switch en Ethernet

Installation du Serveur

J'ai installé FOG sur un PC dédié tournant sous Debian 12. L'installation est assez simple avec le script officiel :

  • Installation de Debian 12 en mode serveur (pas d'interface graphique)
  • Mise à jour du système et installation des dépendances
  • Téléchargement et exécution du script d'installation FOG
  • Configuration du serveur DHCP pour le boot PXE
  • Configuration du serveur TFTP pour l'envoi des images
  • Activation de l'interface web sur le port 80

Préparation des Images

Avant de déployer, il faut créer les "images" de référence. Une image, c'est une copie complète d'un système déjà configuré.

Processus de création d'image :

  • Installer Windows 11 ou Ubuntu 24.04 sur un PC modèle
  • Installer tous les logiciels nécessaires (Office, navigateurs, outils pédagogiques)
  • Configurer les paramètres par défaut
  • Capturer l'image avec FOG (upload vers le serveur)
  • L'image est maintenant disponible pour déploiement sur tous les PC

Images Créées

  • Windows 11 x64 Éducation : Version complète avec Office, Chrome, VS Code
  • Ubuntu 24.04 LTS : Version légère pour cours de programmation

Capture d'une image Windows 11 configurée vers le serveur FOG

Configuration des PC Clients

Pour que les PC puissent démarrer sur le réseau, il faut configurer leur BIOS/UEFI :

  • Activer le boot PXE (Network Boot) dans le BIOS
  • Mettre le boot réseau en priorité avant le disque dur
  • Activer l'UEFI pour Windows 11 (obligatoire)
  • Désactiver le Secure Boot si nécessaire

Cette étape doit être faite une seule fois sur chaque PC. Après, tout se fait automatiquement.

Déploiement en Action

Une fois tout configuré, le déploiement devient ultra simple. Voici comment ça se passe en pratique :

  • Le prof se connecte à l'interface web FOG depuis son PC
  • Il sélectionne les PC à déployer (ou tous d'un coup)
  • Il choisit l'image à envoyer (Windows 11 ou Ubuntu 24.04)
  • Il lance le déploiement
  • Les PC s'allument, bootent sur le réseau, et reçoivent l'image automatiquement
  • 30 minutes plus tard, tous les PC ont le même système installé

Résultat : ce qui prenait 10 heures à la main (30 min × 20 PC) se fait maintenant en 30 minutes. Gain de temps massif !

Avantages de FOG

Gains Concrets

  • Gain de temps : 10 heures → 30 minutes pour déployer 20 PC
  • Fiabilité : Tous les PC ont exactement la même config, zéro erreur humaine
  • Flexibilité : Changement Windows ↔ Ubuntu en quelques clics
  • Maintenance : PC planté ? On redéploie l'image en 30 min
  • Pas de clés USB : Tout passe par le réseau, plus simple
  • Multicast : Envoyer l'image une seule fois vers 20 PC simultanément

Points d'Attention

Quelques contraintes à respecter pour que tout fonctionne :

  • Connexion Ethernet obligatoire : Le Wi-Fi ne supporte pas le boot PXE
  • Serveur toujours allumé : Il doit être disponible pendant tout le déploiement
  • Boot PXE activé : À configurer dans le BIOS de chaque PC
  • Compatibilité UEFI : Nécessaire pour Windows 11
  • Espace disque serveur : Prévoir ~50GB par image stockée

Résultats & Bilan

Le projet FOG a été un succès complet. La salle informatique peut maintenant être reconfigurée en 30 minutes au lieu de plusieurs heures. Les profs peuvent changer de système selon les besoins des cours sans perdre de temps.

Ce projet m'a permis de comprendre :

  • Le fonctionnement du boot réseau (PXE, TFTP)
  • L'administration de serveurs Linux en production
  • Le déploiement d'OS à grande échelle
  • La gestion d'infrastructure réseau éducative
  • L'importance de l'automatisation pour gagner du temps

Le système est maintenant utilisé régulièrement par les profs pour préparer les salles avant les cours ou les examens. Mission accomplie !

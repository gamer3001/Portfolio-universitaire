Virtual Arcade

Ma VM préférée du datacenter EPIL : plateforme gaming retro avec passthrough GPU et interface PlayNite

L'Idée du Projet

Lors du développement du datacenter EPIL, on s'est dit : "Pourquoi ne pas tester les capacités du serveur de manière ludique ?" L'idée est née : créer une VM dédiée au gaming rétro avec émulation de consoles classiques.

Le serveur R730 était puissant, mais pas assez pour émuler la Nintendo Switch. Par contre, la Wii et la SNES ? Parfait ! On a donc créé la VM-Émulation, qui est rapidement devenue mon projet préféré du datacenter.

Interface PlayNite en fullscreen : lancement automatique au démarrage

Configuration de la VM

La VM tourne sous Windows 11 Pro pour une compatibilité maximale avec les émulateurs. Configuration :

  • OS : Windows 11 Pro (sans compte Microsoft)
  • CPU : 4 cœurs alloués du Xeon E5-2600
  • RAM : 12GB DDR4
  • Stockage : SSD 500GB dédié
  • GPU : Carte graphique en passthrough PCIe
  • Émulation TPM 2.0 : Pour Windows 11

Le Passthrough GPU

Le passthrough GPU est LA technique qui change tout pour l'émulation sur VM. Concrètement, on donne un accès direct de la VM à une carte graphique physique, contournant la couche d'abstraction de Proxmox.

Résultat : performances quasi-natives, comme si le GPU était installé directement dans un PC physique. C'est essentiel pour l'émulation, surtout pour les jeux 3D de Wii qui demandent beaucoup de GPU.

Avantages du Passthrough

  • Performances graphiques natives (~95% des perfs réelles)
  • Réduction drastique de l'input lag
  • Support complet OpenGL/Vulkan pour émulateurs
  • Fluidité 60 FPS stable en émulation Wii
  • Possibilité d'upscaling HD (720p → 1080p)

Mario Kart Wii tournant à 60 FPS en 1080p via émulateur Dolphin

PlayNite : L'Interface Ultime

PlayNite est un launcher open-source qui unifie tous les jeux et émulateurs dans une seule interface magnifique. On l'a configuré pour qu'il se lance automatiquement en fullscreen au démarrage de la VM.

Résultat : quand on allume la TV et qu'on démarre la VM, on tombe directement sur une interface type console de salon, sans voir Windows. C'est exactement l'expérience qu'on voulait !

  • Lancement auto au démarrage Windows
  • Mode fullscreen pour expérience console
  • Détection automatique des ROMs
  • Jaquettes et métadonnées automatiques
  • Support manettes Xbox/PlayStation
  • Interface navigable à la manette

Émulateurs Installés

On a installé plusieurs émulateurs pour couvrir différentes consoles rétro. Chacun est configuré pour les meilleures performances :

Liste des Émulateurs

  • Dolphin (Wii/GameCube) : Émulateur principal, upscaling 1080p, 60 FPS stable
  • SNES9x (Super Nintendo) : Émulation parfaite, filtres CRT optionnels
  • PCSX2 (PlayStation 2) : En test, performances correctes

Le Défi de l'Input Lag

Les émulateurs ne sont pas conçus pour tourner sur des VMs. On a donc observé un décalage (input lag) entre nos actions à la manette et ce qui se passe à l'écran.

Solution trouvée : installer une TV dédiée connectée directement à la sortie GPU de la VM. Résultat : input lag divisé par 3, expérience de jeu fluide et réactive !

Le passthrough GPU a aussi énormément aidé en réduisant les couches de virtualisation entre la manette et l'affichage.

Migration entre Serveurs

Pour installer la carte graphique sur le R730, j'ai dû migrer temporairement la VM vers le R430. Proxmox rend ça super simple :

  • Migration à chaud (sans éteindre la VM)
  • Installation de la carte GPU sur R730
  • Configuration du passthrough PCIe
  • Migration de retour avec GPU fonctionnel

C'est une des forces de Proxmox : la flexibilité totale pour déplacer les VMs entre nœuds du cluster.

Logiciels Installés

On a utilisé Ninite pour installer rapidement tous les logiciels nécessaires :

  • Google Chrome (pour télécharger les ROMs)
  • Visual Studio C++ Redistributable (requis par émulateurs)
  • DirectX Runtime (pour performances GPU)
  • Drivers GPU à jour
  • Drivers manettes (Xbox, PlayStation)

Résultat Final

La VM-Émulation est maintenant ma VM préférée du datacenter EPIL. Elle prouve qu'on peut créer une vraie console de salon retro avec de la virtualisation et du matériel serveur.

Performances : 60 FPS stables en Wii, 0 lag en SNES, expérience fluide à la TV. Le passthrough GPU a été la clé du succès.

Et bonus : c'est devenu un excellent moyen de faire des pauses gaming entre les séances de configuration serveur !

Le Chef d'Orchestre

N8N est le cerveau qui connecte tous mes services ensemble. C'est un outil d'automatisation workflow qui permet de créer des scénarios complexes reliant Home Assistant, Frigate, Kara, mes emails, APIs externes... tout peut être orchestré visuellement.

Au lieu d'avoir des scripts éparpillés partout, j'ai centralisé toute la logique d'automatisation dans N8N. Chaque workflow est visuel, facile à débugger, et peut être modifié en quelques clics. C'est la colle qui fait tenir tout l'écosystème ensemble.

Interface N8N montrant plusieurs workflows actifs

Architecture & Déploiement

N8N tourne dans le conteneur LXC 106 sur le ProxmoxEliteBook. Avec 2GB de RAM et 2 cores CPU, c'est parfaitement dimensionné pour gérer des dizaines de workflows simultanés. L'uptime de plus de 6 jours prouve sa stabilité - il tourne en continu sans broncher.

Les workflows sont stockés dans une base de données SQLite locale, avec backup automatique quotidien sur TrueNAS. Si je dois reconstruire N8N, je restaure simplement la base et tous mes workflows sont de retour.

Workflows Actifs

  • Kara Email Monitor : Kara analyse mes emails importants et me fait un résumé
  • Frigate Alert System : Détection personne → Screenshot → Notification avec image
  • Home Assistant Backup : Backup automatique quotidien vers TrueNAS
  • Weather Automation : Récupère météo → Ajuste chauffage et volets
  • Kara Voice Control : Commandes vocales ESP32 → Actions domotique

Intégration Kara

N8N joue un rôle crucial dans l'orchestration de Kara, mon assistant IA. C'est N8N qui gère la communication entre Kara (sur la VM-IA-Server), OpenWebUI, Home Assistant, et tous les autres services.

Quand je donne un ordre vocal à Kara via l'ESP32, voici ce qui se passe : ESP32 → N8N → Ollama (pour comprendre l'intention) → Home Assistant (pour exécuter l'action) → N8N → ESP32 (confirmation vocale). Tout ça en moins d'une seconde.

Nodes & Intégrations

N8N dispose de centaines de "nodes" pré-faits pour se connecter à des services populaires. J'utilise notamment :

  • Home Assistant Node : Contrôle total de la domotique
  • HTTP Request : Pour appeler Ollama, Frigate, et APIs custom
  • Email (IMAP/SMTP) : Surveillance et envoi d'emails
  • Webhook : Réception d'événements de Frigate, ESP32, etc.
  • Schedule Trigger : Automatisations temporelles
  • IF Node : Logique conditionnelle complexe
  • Code Node : JavaScript custom pour logique avancée

Exemple Concret : Alerte Frigate

Voici un workflow que j'utilise quotidiennement. Quand Frigate détecte une personne à l'entrée :

  1. Frigate envoie un webhook à N8N avec l'événement
  2. N8N vérifie si je suis à la maison (via Home Assistant)
  3. Si je suis absent, N8N récupère le snapshot de Frigate
  4. N8N envoie une notification push avec l'image sur mon téléphone
  5. N8N demande à Kara d'analyser l'image (qui est-ce ?)
  6. Si c'est un livreur, N8N allume les lumières extérieures

Tout ça orchestré automatiquement, sans intervention. C'est la puissance de N8N.

Debugging & Monitoring

N8N offre des outils de debugging incroyables. Chaque exécution de workflow est loggée avec toutes les données qui transitent à chaque étape. Si un workflow échoue, je peux voir exactement où et pourquoi.

J'ai configuré des alertes pour m'avertir si un workflow critique échoue plusieurs fois. Par exemple, si le backup automatique de Home Assistant rate 2 fois de suite, je reçois une notification pour investiguer.

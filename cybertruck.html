Cybertruck Intelligent

Robot autonome capable d'éviter des obstacles, suivre une personne et explorer de manière autonome

Le Projet

Le Cybertruck Intelligent est un robot autonome que j'ai conçu et réalisé entièrement, de la programmation Arduino au boîtier imprimé en 3D. L'idée était de créer un petit véhicule intelligent capable de naviguer dans son environnement de manière totalement autonome.

Ce projet combine électronique, programmation, design 3D et impression additive. Le robot embarque plusieurs capteurs ultrasoniques, un écran LCD, des LEDs de signalisation et peut être contrôlé en 3 modes différents.

Note : J'avais prévu de faire une vidéo YouTube complète sur ce projet, mais je n'ai pas réussi à en faire quelque chose d'assez vidéoludique pour le publier. Le robot fonctionne parfaitement, mais la vidéo finale ne me satisfaisait pas niveau qualité de contenu.

Les 3 Modes de Fonctionnement

Le robot dispose de 3 modes distincts, sélectionnables via deux boutons. L'écran LCD affiche le mode actif pour faciliter l'utilisation.

🚧
Évitement d'Obstacles

Le robot détecte les obstacles devant lui et change automatiquement de direction pour les éviter

👤
Suivi de Personne

Le robot suit une personne en gardant une distance de sécurité constante, comme un compagnon

🗺️
Exploration Autonome

Le robot explore une zone de manière aléatoire en évitant automatiquement les obstacles rencontrés

Comment Ça Fonctionne ? (Le Code)

Le cerveau du robot est une carte Arduino programmée en C++. Voici comment il prend ses décisions :

Logique de Décision

  • Sélection du mode : Deux boutons permettent de naviguer entre les 3 modes. L'écran LCD affiche le mode actif.
  • Capteurs ultrasoniques : Mesurent en permanence la distance des objets autour du robot (avant, gauche, droite).
  • Prise de décision : Si un obstacle est trop proche (<20cm), le robot change de direction ou ralentit automatiquement.
  • Signalisation LED : Vert = OK, Jaune = Obstacle proche, Rouge = Obstacle critique.
  • Adaptation : En mode suivi, le robot ajuste sa vitesse pour maintenir la distance avec la personne.

Simple mais efficace ! Le code fait environ 500 lignes et gère tous les capteurs, moteurs et l'affichage en temps réel.

Schéma Électronique

Le câblage est la partie technique du projet. Chaque composant doit être relié correctement à l'Arduino pour que tout fonctionne.

Composants Électroniques

  • Arduino Uno : Le cerveau du robot qui exécute le code
  • 3x Capteurs ultrasoniques HC-SR04 : Détection d'obstacles (avant, gauche, droite)
  • Driver moteur L298N : Contrôle des 2 moteurs DC pour les mouvements
  • 2x Moteurs DC : Propulsion et direction du robot
  • Écran LCD 16x2 : Affichage du mode actif
  • 3x LEDs (Vert, Jaune, Rouge) : Signalisation visuelle de l'état
  • Buzzer : Alarme sonore en cas d'obstacle critique
  • 2x Boutons : Sélection du mode de fonctionnement
  • Batterie 9V : Alimentation autonome du système

Les LEDs ajoutent un vrai plus pour la sécurité : on sait immédiatement si le robot détecte quelque chose. Vert = tout va bien, Jaune = attention obstacle proche, Rouge = obstacle critique !

Design 3D & Impression

Pour que tout soit bien organisé et protégé, j'ai conçu un boîtier compact dans Fusion 360. Le design s'inspire (un peu) du Cybertruck de Tesla avec ses lignes angulaires.

Le boîtier a été optimisé pour :

  • Accueillir tous les composants de manière compacte
  • Avoir des ouvertures précises pour les 3 capteurs ultrasoniques
  • Permettre l'accès aux boutons et à l'écran LCD
  • Laisser voir les LEDs de signalisation
  • Être imprimable en une seule pièce (ou en 2 parties assemblables)
  • Avoir un look futuriste qui en jette !

Impression 3D en PLA, environ 8 heures d'impression. Le résultat est solide et parfaitement adapté au projet.

Câblage & Assemblage

L'assemblage est la partie où tout prend vie. Il faut être méthodique pour que rien ne soit oublié.

Étapes d'assemblage :

  • Montage des moteurs : Fixation des 2 moteurs DC sur le châssis du robot
  • Installation des capteurs : Placement précis des 3 capteurs ultrasoniques (avant, gauche, droite)
  • Câblage Arduino : Connexion de tous les composants selon le schéma électronique
  • Test des connexions : Vérification que les LEDs, le buzzer et l'écran fonctionnent
  • Montage du boîtier : Installation de tous les composants dans le boîtier imprimé
  • Fermeture finale : Une fois tout testé, on ferme le boîtier et c'est parti !

Le câblage est la partie la plus délicate : chaque fil doit aller à la bonne broche de l'Arduino. Une erreur et ça ne fonctionne pas. Heureusement, j'avais préparé un schéma détaillé !

Tests & Validation

Une fois l'assemblage terminé, place aux tests ! Il faut valider que chaque mode fonctionne correctement.

Tests Effectués

  • Mode Évitement d'Obstacles : Le robot détecte un obstacle à gauche et change immédiatement de direction. Les LEDs passent au jaune puis au rouge si trop proche. Validé ✓
  • Mode Suivi de Personne : Le robot garde une distance de sécurité (~30cm) tout en suivant la personne. Il s'arrête si la personne s'arrête. Validé ✓
  • Mode Exploration Autonome : Le robot se déplace de manière aléatoire, explorant la zone et évitant automatiquement les obstacles rencontrés. Validé ✓

Tous les modes fonctionnent parfaitement ! Le robot est réactif, les capteurs sont précis, et la signalisation LED rend tout très visuel.

Améliorations Possibles

Ce projet pourrait être amélioré de plusieurs façons :

  • Ajouter une caméra pour reconnaissance d'objets via IA
  • Intégrer un module Bluetooth pour contrôle depuis smartphone
  • Utiliser des capteurs infrarouges supplémentaires pour détecter les rebords
  • Implémenter un système de cartographie SLAM pour mémoriser l'environnement
  • Ajouter un bras robotique pour manipulation d'objets
  • Améliorer l'autonomie avec une batterie Li-Po plus puissante

Même si je n'ai pas publié la vidéo YouTube (je n'étais pas satisfait du rendu ), le robot fonctionne parfaitement et démontre bien les concepts de robotique autonome.

Ce projet m'a appris énormément sur :

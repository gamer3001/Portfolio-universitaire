Tailscale VPN

Accès distant sécurisé au datacenter EPIL : VPN Zero Trust sans ouverture de ports

Le Besoin d'Accès Distant

Pendant le développement du datacenter EPIL, j'ai rapidement eu besoin d'accéder aux serveurs depuis chez moi pour continuer à travailler en dehors des heures de cours. Le problème : comment accéder de manière sécurisée aux serveurs du lycée sans compromettre la sécurité du réseau ?

Les solutions classiques (port forwarding, VPN traditionnel) nécessitent d'ouvrir des ports sur le routeur de l'école, ce qui pose des problèmes de sécurité et nécessite l'intervention du service informatique. J'ai donc cherché une alternative moderne et sécurisée.

Pourquoi Tailscale ?

Tailscale est une solution VPN moderne basée sur WireGuard qui utilise une architecture Zero Trust NAT traversal. Concrètement, cela signifie :

  • Aucun port à ouvrir - Fonctionne même derrière NAT et firewall
  • Chiffrement de bout en bout - Sécurité maximale avec WireGuard
  • Configuration simple - Installation en 3 commandes
  • Zero Trust - Authentification par appareil, pas par réseau
  • Gratuit pour usage personnel - Jusqu'à 100 appareils
  • Multi-plateforme - Windows, Linux, macOS, iOS, Android

Architecture Tailscale : tunnel sécurisé sans ouverture de ports

Installation sur Proxmox

L'installation de Tailscale sur le serveur Proxmox est extrêmement simple. Voici les commandes que j'ai utilisées :

# Installation de Tailscale
curl -fsSL https://tailscale.com/install.sh | sh

# Activation du service
systemctl enable --now tailscaled

# Connexion au réseau Tailscale
tailscale up

La dernière commande génère un lien d'authentification que j'ai ouvert dans mon navigateur pour lier le serveur à mon compte GitHub (nécessaire pour Tailscale).

Configuration du Réseau

Une fois Tailscale installé, chaque appareil reçoit une IP privée du réseau 100.x.x.x. J'ai configuré :

Appareils Connectés

  • Proxmox R730 - 100.64.x.x (serveur principal)
  • Proxmox R430 - 100.64.x.x (serveur secondaire)
  • Mon laptop personnel - 100.64.x.x (client)
  • Mon téléphone - 100.64.x.x (monitoring mobile)

Avec cette configuration, je peux accéder à l'interface Proxmox depuis n'importe où comme si j'étais sur le réseau local du lycée : https://100.64.x.x:8006

Sécurité & Avantages

Tailscale offre plusieurs avantages de sécurité par rapport aux VPN traditionnels :

  • Authentification par appareil - Chaque device doit être autorisé individuellement
  • Pas de serveur central - Connexions peer-to-peer directes quand possible
  • Chiffrement WireGuard - Protocole moderne ultra-sécurisé
  • Révocation instantanée - Je peux désactiver un appareil en 1 clic
  • Logs d'accès - Je vois qui se connecte et quand
  • Aucune exposition internet - Les serveurs restent invisibles depuis internet

Utilisation Quotidienne

Depuis l'installation de Tailscale, je peux travailler sur le datacenter EPIL depuis chez moi comme si j'étais au lycée. Cas d'usage typiques :

  • Administration Proxmox - Créer/modifier des VMs à distance
  • Accès SSH - Terminal direct sur les serveurs
  • Monitoring - Vérifier l'état des services 24/7
  • Backups - Lancer des sauvegardes manuelles si besoin
  • Debugging - Résoudre les problèmes sans être sur place
  • Développement - Tester mes configs en temps réel

Intégration avec le Datacenter

Tailscale s'intègre parfaitement avec l'infrastructure du datacenter EPIL. J'ai configuré :

  • Accès direct aux interfaces web (Proxmox, TrueNAS, Home Assistant)
  • SSH sur tous les serveurs et VMs
  • Accès aux shares SMB de TrueNAS
  • Monitoring des logs en temps réel
  • Connexion aux VMs Windows via RDP

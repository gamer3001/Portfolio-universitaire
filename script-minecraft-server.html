Script Minecraft Server

Un script Proxmox VE Helper-Script qui déploie un conteneur LXC prêt à héberger un serveur Minecraft, avec panel web Crafty Controller et tunnel Playit.gg sans ouverture de port.

Un serveur Minecraft déployé sans ouvrir aucun port

Ce script, dans le même esprit que les Proxmox VE Helper-Scripts communautaires, crée un conteneur LXC non privilégié et installe tout ce qu'il faut pour héberger un serveur Minecraft moddé ou avec plugins : Java 17 et 21, Crafty Controller (panel web de gestion) et Playit.gg (tunnel reverse). Aucun port n'a besoin d'être ouvert sur le routeur.

Ce que fait le script

  • Crée un conteneur LXC non privilégié (choix entre Debian 12, Ubuntu 22.04 LTS ou 24.04 LTS)
  • Demande les ressources de façon interactive (par défaut 4 vCores / 8 Go RAM / 20 Go disque)
  • Installe Java 17 et 21 (Eclipse Temurin) pour couvrir Vanilla, Forge, Fabric, Paper et les serveurs hybrides
  • Installe Crafty Controller v4 : création/gestion de serveurs, upload de mods/plugins, sauvegardes, accès console
  • Installe Playit.gg : tunnel reverse qui expose le serveur publiquement sans forwarder le port 25565 sur le routeur
  • Affiche la progression avec un spinner à chaque étape, et s'arrête proprement avec le log d'erreur complet en cas de problème

Pourquoi c'est raisonnablement sûr

  • Aucun port entrant sur le routeur : Playit.gg ouvre une connexion sortante depuis le conteneur vers ses serveurs relais, c'est ce tunnel qui porte le trafic des joueurs — l'IP de la maison n'est jamais exposée
  • Conteneur non privilégié : même en cas de faille dans un mod ou un plugin, un attaquant resterait cantonné dans le LXC, sans accès à l'hôte Proxmox ni au reste du réseau
  • Crafty tourne avec un utilisateur dédié non-root, pas en root
